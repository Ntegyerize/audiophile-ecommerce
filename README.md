# Audiophile – E-commerce Website

A responsive e-commerce website for an audio equipment brand, built as a Frontend Mentor portfolio project.

## Project Overview

The goal of this project is to recreate the Audiophile e-commerce experience using the supplied Figma designs and design system.

The project focuses on responsive frontend development, reusable UI components, accessibility and interactive shopping functionality.

## Technologies

- HTML5
- CSS3
- JavaScript

## Design Reference

The project follows the supplied Audiophile Figma designs and design system.

The specified visual guidelines cover:
- Manrope typography
- Brand colours and design tokens
- Button variants and interaction states
- Form elements
- Responsive layouts

## Current Development Status

**In progress.**

Initial development includes:
- Figma design inspection
- Project structure and CSS architecture
- Initial responsive header implementation

## Planned Features

- Responsive navigation
- Product category browsing
- Product detail pages
- Shopping cart functionality
- Checkout experience
- Responsive layouts across mobile, tablet and desktop
